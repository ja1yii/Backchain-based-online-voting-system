Five steps between a voter and a counted ballot

  1. 1

    Register once

    A voter enrolls with their national ID and a short face capture used only to build their verification profile.

  2. 2

    Show up to vote

    On election day, the voter opens SecurePoll and starts a session tied to their registered constituency.

  3. 3

    Face verification

    The camera matches the voter's live face against their enrollment record. A mismatch stops the session immediately.

  4. 4

    One-time password

    A six-digit code is sent to the voter's registered phone number and expires in 60 seconds — a second factor the camera alone can't fake.

  5. 5

    Cast & confirm

    The voter selects a candidate once. The ballot is recorded and the choice can't be reopened or changed.

Built with

Frontend

HTML5, CSS3, vanilla JavaScript — this page. No frameworks required to run it.

Face recognition

In production: a model such as OpenCV/Dlib or a cloud face-match API compares live capture to the enrollment photo.

OTP delivery

An SMS/email gateway (e.g. Twilio) issues a time-boxed code tied to the voter's session.

Backend & storage

A server (e.g. Node/Django/PHP) with an encrypted database records one ballot per verified voter ID.
